Descriptions of FFX Commands and Properties are generated during build time.

In addition, task-oriented Guides are available under `src/site/xdoc/guides`:
- Preparing-a-Structure.xml — End-to-end prep from PDB → solvation → minimization → NVT/NPT → production.
- Running-MD.xml — Practical `Dynamics` usage, thermostats/barostats, I/O, restarts, and performance tips.
- Constant-pH-MD.xml — Setup and run `PhEnergy`/`PhMinimize`/`PhDynamics`, titration models.
- Troubleshooting-and-Reproducibility.xml — Common issues, diagnostics, and reproducible workflows.

Worked examples are also grouped under the Guides section (`src/site/xdoc/guides`):
- input.xml — Input files and force field selection for FFX calculations.
- convertFileFormat.xml — Conversion between CIF, PDB, and XYZ formats.
- gpuSideChain.xml — GPU accelerated many-body side-chain optimization.
- dee.xml — Side-chain optimization and mutation via Many-Body DEE.
- gauche.xml — Absolute organic crystal thermodynamic stability.
- polymorphNPTsearch.xml — Thermodynamic NPT organic crystal polymorph search.
- mcOSRWSolvationFreeEnergy.xml — GPU accelerated MC-OST solvation free energy.
- xray.xml — AMOEBA-assisted X-ray refinement.
